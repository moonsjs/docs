## Cross-package

- **Errors**: format; runtime catalog `MOONS_ERROR_CODES` (22 codes);
  structured catalog: `moons errors --json` / MCP `explain_error`.
- **Virtual modules** (all `\0`-prefixed): `virtual:moons/routes`,
  `virtual:moons/api`, `virtual:moons/config`, `virtual:moons/client-entry`,
  `virtual:moons/server-entry` — see [`vite.md`](vite.md).
- **Global server runtime**: `globalThis.__moons_ssr`, `globalThis.__moons_callInProcess`
 (set when `@moonsjs/server` loads) — used by the stub
- **Ctx**: a global type generated by typegen into `.moons/context.d.ts`;
 `ctx.__prerender === true` during a prerender build.
- **Plugin config (`plugins`)**: types are validated strictly (keys outside the
  shape → `E_CONFIG_INVALID`) and **executed** — `addRoute`/`addMiddleware`
  (observation), `extendContext` (merge ctx per request), `onStart`/`onReady`/
  `onShutdown` — see `../decisions/0022-m7-kontrak-ux.md`.
